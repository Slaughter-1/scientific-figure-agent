## 使用限制

1. 默认文本规划是规则式，不保证任意论文段落均可正确理解。
2. 复杂分支、密集图、长标签、线路交叉与标签净空仍可能触发 `needs_review`。
3. 启发式分数不能代替质量评审，文件完整性不能证明图的科学语义正确。
4. 结构图生成与正式任务 ZIP 导出是不同入口；后者须满足版本、证据和许可门禁。
5. 本地 HTTP 服务没有生产账号认证体系，默认只应在回环地址使用。
6. 外部资产登记/随包交付不等于已合成进图，也不等于自动取得用途授权。
7. 图标题只在预览层显示而未写入 Draw.io 标题单元格，是本周期明确保留的设计。
8. 数据图使用独立渲染尺寸，不能套用结构图的栏宽承诺。
